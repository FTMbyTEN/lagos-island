# Lagos Island

- This project is worked on from two computers and synced through GitHub (github.com/FTMbyTEN/lagos-island). After finishing and checking a change, commit it to `main` and push it straight away, without asking. Pull before starting work.
- If `git` isn't recognized in a session, call it by its full path: `C:\Program Files\Git\cmd\git.exe`.
- Preview locally with the `web` config in `.claude/launch.json`. It serves `web/` at http://localhost:5500 using `.claude/serve.ps1`, with no Node or Python needed. Add `?night=0` or `?night=1` to force day or night, and `?at=column,row` to start the view at a spot.
